GitHub connection

        
Connect once to save changes directly to your GitHub repository. This triggers a deploy and the live site updates in about 1 minute — no manual commits needed.

        

          
        

      

      

        
How it works

        
The admin panel writes config.json to your repo via the GitHub API using a Personal Access Token (PAT). The token is stored only in your browser (localStorage) — it never leaves your device. Anyone can see the admin UI, but they cannot save without a valid token.

      

    

  











  

    
🔗 Connect to GitHub

    
Enter your repository details and a Personal Access Token. This lets the admin panel save changes directly without manual commits.

    

      Option A — Fine-grained token (recommended):

      1. Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens

      2. Click Generate new token

      3. Under Repository access, choose Only select repositories → pick embedbot

      4. Under Repository permissions, find Contents and set it to Read and write

      5. Generate and paste the token below


      Option B — Classic token:

      Go to Personal access tokens → Tokens (classic), generate with the repo scope checked.
